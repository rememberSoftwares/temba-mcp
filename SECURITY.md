# Security policy

## Reporting a vulnerability

Please report suspected security vulnerabilities in Temba privately to
[emilien.lancelot@numspot.com](mailto:emilien.lancelot@numspot.com).
Do not open a public issue containing vulnerability details before a fix or
disclosure plan has been agreed upon.

Include the affected version, a description of the issue, steps to reproduce
or a minimal proof of concept, and the potential impact. Remove credentials,
tokens, personal data and other sensitive information from any attachments.

We will review the report and coordinate remediation and disclosure with you.

temba-mcp est déployé (release {{ .Release.Name }}).

1. Accès (dev) :
   kubectl port-forward svc/{{ include "tembamcp.fullname" . }} 18080:8080
   → MCP pour les agents : http://localhost:18080/mcp
   → page d'auth OAuth  : http://localhost:18080/auth

2. Token admin (Secret {{ include "tembamcp.adminSecretName" . }}) :
   kubectl get secret {{ include "tembamcp.adminSecretName" . }} -o jsonpath='{.data.{{ include "tembamcp.adminTokenKey" . }}}' | base64 -d
   → bearer de l'API admin /servers (jamais envoyé au LLM).

3. OAuth : au premier usage d'un serveur oauth: {} , le LLM renvoie un lien
   personnel /auth?t=... à ouvrir dans le navigateur (valable 15 min).

4. Une seule réplique / un seul process : tokens OAuth et catalogue dynamique
   uniquement en mémoire. Un redémarrage nécessite de reconnecter les MCP OAuth
   et de recréer les entrées dynamiques. Le catalogue Helm reste disponible.
